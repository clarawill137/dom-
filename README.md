# Дом

Уютное расширение SillyTavern для God Complex: их квартира по комнатам, хэды на холодильнике и хэд-машина.
Без драмы, с картинками. Живёт рядом с **Life** (мост `LifeBridge`): его время истории, умная модель со сводом,
картинки через Гардероб, и общая полка хедканонов.

## Что внутри (0.1)

- **Комнаты** — кухня, гостиная, детская, спальня, балкон, мастерская, гараж. Каждую можно нарисовать
  (по лорбуку квартиры, если он есть; картинка своя у каждой эпохи) или поставить свою. Мастерская и гараж ведут в Ангар.
- **Холодильник** (кухня) — хэды полароидами на магнитах. Это та же полка, что Life → Психика → Хедканоны: модель держит
  их за правду и вспоминает к месту, когда герои в сцене. ⏸ — придержать (висит, но модели не уходит), ✕ — снять.
  Хэд, записанный руками в Life, тоже висит тут — его можно нарисовать.
- **Хэд-машина** — умная модель Life придумывает четыре хэда по карточкам, ядру характера, вкусам и своду истории.
  Настроение — 🎲 кубиком (d20 на каждый хэд: 1 абсурд · 2–6 быт · 7–11 мило · 12–15 смешно · 16–19 про них · 20 золотой)
  или руками: мило, быт, смешно, про них, тёплая психология, абсурд, золотой. Про кого — любые из группы. «О чём» — по желанию.
  Каждый хэд сразу рисуется (лица — рефами из Гардероба, стиль — картинок Life); «на холодильник» — и модель его знает.
  Заделы её истории (Узнавание → «не знает никто», записи лорбуков «Задел: …») машина не трогает: что задевает их
  ключи — не показывается. Повторы уже записанного — тоже.

## Дальше по комнатам

Кухня — Кухня Баки, Банка хорошего · Гостиная — Полка Баки, Плюшевый зоопарк, Колода «вечер вдвоём», Догоняем век,
Банка свиданий · Детская — кроватка и обои, имена для малыша · Балкон — огород Баки.

## Команда

`/dom` — открыть, `/dom hc` — сразу хэд-машина, `/dom kitchen` — кухня. Палочка → «Дом». `globalThis.Dom.open(room)`,
`Dom.openGen()` — для соседей.

## Данные

- `chat_metadata.dom` — броски машины (последние шесть) и картинки комнат (`комната:эпоха`).
- `chat_metadata.life.pair.hc` — хедканоны Life; Дом добавляет к записи `img`, `src: 'dom'`, `vibe`, `at`.
